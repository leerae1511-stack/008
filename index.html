4. Draw / edit profile

The orange rectangle is the workspace only. Draw the actual tool shape; it does not have to be drawn to screen scale. Points can be dragged. Use Add point, delete a point or delete a range, then reconnect automatically. Added points can be Straight or Curve. Curve points smooth the outline between neighbouring points. There is no limit on Added Points.

Undo: Undo reverses only your edits, newest first. The generated/imported outline is the baseline and is never removed by Undo.
Tip: touching the orange reference-frame border does not add a point. Point editing is explicit: drag an existing point to move it, or use Add point to insert one. A normal tap on an existing point selects it for dragging rather than adding another point.

Curve Editing

Every profile point can be Straight or Curve. Straight points stay fixed on the profile. A Curve point acts as the curve control between the surrounding profile points and can be moved to shape the finger-access recess. For example: 6 = Straight → 7 = Curve → 8 = Straight.

6. Engineering geometry check

The check is performed after final physical-grid dimensions and curve sampling, before STL export. It checks the profile and cleared profile for self-intersection, envelope limits and curve/profile geometry.

7. Saved Profiles — JSON

Use these buttons to save or restore the current tool profile. An existing profile JSON can be imported here. JSON is the reusable profile file; it is not the STL used for printing.

8. STL test export

Exports the positive pocket-cut volume used in the tray workflow. The final sampled tool outline is the STL cut boundary, and the final curved profile is the cutter boundary.
